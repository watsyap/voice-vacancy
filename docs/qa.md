# QA: как вызвать каждое состояние

Для проверяющего: как попасть в каждое состояние flow.md §3 и проверить AC (spec §9). Работает и в демо-режиме (без `ANTHROPIC_API_KEY`), и с ключом.

Сайт: https://voice-vacancy.vercel.app. Локально: `npm run dev:full` (UI + `/api`, без ключа — демо).

Инструменты Chrome DevTools, которые понадобятся:
- **Network → Offline** — нет сети.
- **Network → Request blocking** (⋮ → More tools) — заблокировать `/api/analyze` или `/api/generate`.
- **Значок слева от адреса → Микрофон** — разрешить или заблокировать.
- **Rendering → Emulate CSS prefers-reduced-motion: reduce**; **prefers-color-scheme: dark**.
- **Application → Local Storage → `vv:session:v1`** — сохранённая сессия; удалить — чистый старт.

Чистый старт: удалить `vv:session:v1` и обновить страницу.

| S | Состояние | Как вызвать | Что проверить |
|---|---|---|---|
| S1 | Первый вход | Чистый старт | Пустое кольцо, «4 вопроса…», «Начать», «Ответить текстом». Метки «Демо-режим» нет |
| S2 | Запрос микрофона | S1 → «Начать» при неразрешённом микрофоне | Системный диалог, подпись «Разрешите доступ к микрофону» |
| S3a | Микрофон запрещён | Заблокировать микрофон для сайта → «Начать» | Текстовый режим, строка с инструкцией «значок слева от адреса → Микрофон → Разрешить» |
| S3b | Микрофона нет | Отключить микрофон в системе (или занять его другим приложением) → «Начать» | «Микрофон не найден — отвечайте текстом» |
| S3c | Браузер не поддерживает | Открыть в Firefox → «Начать» | Сразу текстовый режим, «Голосовой ввод работает в Chrome и Edge» |
| S4 | Слушаю | «Начать» → разрешить | «Слушаю», штрихи текущего сегмента реагируют на голос, промежуточный текст. AC-4.1–4.4: 4 с тишины после речи завершают ответ, слово «готово» в речи — нет |
| S5 | Тишина 5 с | В S4 молчать 5 с (в тихой комнате) | Пауза, «Нажмите на кольцо, когда будете готовы»; тап по кольцу — снова S4 |
| S6 | Шум / пусто | В S4 шуметь без слов 5 с (стучать, музыка без речи) | «Не разобрал речь…»; после 2 раз подряд основная кнопка — «Ответить текстом» |
| S7 | Слишком короткий | Q1: сказать или ввести «ревью кода» → «Готово» | «Расскажите чуть подробнее», текст сохранён, запись продолжается. AC-7.1: на Q4 «Figma, SQL» → S9 |
| S8 | Пауза | В S4 тап по кольцу или Esc | «Пауза», текст сохранён; «Готово», «Перезаписать», тап — продолжить |
| S9 | Анализ | Ответ не короче порога → «Готово» | «Разбираю ответ», бегущий участок в сегменте, кнопок нет |
| S10 | Понял (полно) | Q1: «ревью кода, планирование спринта, созвоны с заказчиком» | Сегмент заполнен, «Понял: задачи — …»; автоперехода нет (AC-10.3) |
| S10′ | Принято частично | Из S11 → «Пропустить уточнение», или неполный ответ после уточнения | Сегмент частично, «Понял: …» |
| S11 | Уточнение | Q1: «в основном ревью кода каждый день» (одна задача) | «Понял: …» + уточняющий вопрос, запись стартует через 600 мс; ссылки «Пропустить» нет. Ответ дописывается к исходному (AC-11.2) |
| S12 | Анализ упал | Request blocking на `/api/analyze` → ответить | Сегмент приглушён, «Ответ сохранён: <начало ответа>», «Следующий вопрос», «Перезаписать» |
| S13 | Повтор ответа | В S10 / S10′ / S12 / S8 → «Перезаписать» | Сегмент обнуляется, сразу S4 с пустым текстом (S13 мгновенный, decisions.md) |
| S14 | Пропуск | В S4 → «Пропустить» | Сегмент пунктиром, следующий вопрос; на Q4 — «Собрать вакансию» |
| S15 | Возврат к ответу | В S10 / S10′ / S12 / S14 тап по сегменту уже данного ответа | Вопрос N, «Понял: …» прежнего ответа; «Следующий вопрос» — к первому неотвеченному |
| S16 | Генерация | Q4 в S10 / S10′ / S12 / S14 → «Собрать вакансию» | Замыкание кольца 600 мс, затем текст потоком (AC-16.1). Пропущенный Q2 — нет раздела «Проект» (AC-16.2) |
| S17 | Генерация долгая | DevTools → Network → throttling: Custom с задержкой ≥ 10 с (или в коде временно поднять задержку демо) | «Ещё немного…» через 10 с; через 30 с без текста — S18 |
| S18 | Генерация упала | Request blocking на `/api/generate` → «Собрать вакансию» | «Не получилось собрать вакансию. Ответы сохранены», «Повторить». AC-18.2: обновить страницу → S23 с ответами |
| S18′ | Частичный результат | Во время потока S16 включить Offline | Часть текста + «Текст не дописан», «Дописать заново»; текст можно править |
| S19 | Вакансия | Дождаться конца генерации | Мини-кольцо исчезает, «Скопировать» → «Скопировано» на 2 с, в буфере тот же Markdown (AC-19.2). Правка → обновить через ≥ 0,5 с → правки на месте (AC-19.3). «Новая вакансия» — двойное нажатие |
| S20 | Всё пропущено | «Пропустить» на всех 4 вопросах | «Нужен хотя бы один ответ, чтобы собрать вакансию», тап по сегменту → S15 |
| S21 | Оффлайн | Network → Offline в S4 | За ≤ 1 с «Нет сети…», текстовый режим, распознанное в поле (AC-21.1). Ответы → сегмент приглушён (AC-21.2). «Собрать вакансию» → «Соберу вакансию, когда вернётся сеть». Online → очередь разбирается сама, сегменты обновляются, голос снова доступен (AC-21.3) |
| S22 | Вкладка скрыта | В S4 переключиться на другую вкладку и вернуться | «Запись приостановлена» (S8) |
| S23 | Перезагрузка | Ответить на Q1 → обновить страницу | «Продолжим с вопроса N», «Продолжить» (тот же вопрос), «Начать заново» — двойное нажатие. Если вакансия уже собрана — сразу S19. Сессия старше 7 дней — S1 (в Local Storage поменять `savedAt` на старое значение) |
| S24 | Нет громкости | Android Chrome (конфликт захвата микрофона) или браузер без `AudioContext` | Штрихи вспыхивают на каждый новый фрагмент распознавания, а не по громкости |

## Режимы

| Что | Как | Что проверить |
|---|---|---|
| Текстовый режим | «Ответить текстом» в S1 или в записи | Поле с автовысотой до 6 строк, Ctrl+Enter = «Отправить»; «Ответить голосом» возвращает голос с уже введённым текстом |
| Демо-режим | Без `ANTHROPIC_API_KEY` в Vercel | Метка «Демо-режим» появляется после первого ответа API, на S1 её нет |
| Reduced motion | Rendering → prefers-reduced-motion: reduce | Без вращения и волн; громкость — только opacity; заполнение мгновенное; смена вопроса — fade 150 мс |
| Тёмная тема | Rendering → prefers-color-scheme: dark | Цвета из токенов, контраст текста |
| Ширина | DevTools → Device toolbar: 360 px и ≥ 600 px | Нет горизонтальной прокрутки; кольцо 200 / 240 px; вопрос в одну строку на десктопе (24 → 18 px), с переносом на телефоне |
